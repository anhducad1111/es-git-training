# 三輪車（ローバー）検出・姿勢（Yaw角）推定プロジェクトのまとめ

---

### 1. アノテーション仕様と構成

* **使用ツール**: CVAT（Computer Vision Annotation Tool）
* **モデル形式**: YOLOv8-Pose (`Ultralytics YOLO Pose 1.0` 形式で出力)
* **クラス数**: **`1`**（`car-mini`）
* **キーポイント数**: **`2点`**（Skeleton定義）
* **Point 1 (`FRONT`)**: 車体前部中央（配線や基板の先端）
* **Point 2 (`REAR` / `BACK`)**: 車体後部中央（ArUco / AprilTag マーカーの中心）



---

### 2. 2点構成（FRONT / REAR）を採用する理由

* **必要十分な精度**: 平面上の向き（Yaw角 / Heading）の計算は、車体の中心軸ベクトル $\vec{V} = (x_f - x_r, y_f - y_r)$ の2点座標のみで100%求められます。
* **オクルージョン（遮蔽）への強さ**: ポイント数を3〜4点（タイヤ位置等）に増やすと、斜めからの撮影時に奥のタイヤが車体自身に隠れやすくなります。見えない点を減らすことで学習が安定します。
* **アノテーションコストの削減**: 点を増やすと作業負荷が増加し、キーポイント判定の揺れ（ノイズ）の原因になります。2点に抑えることで作業速度と精度を最適化できます。

---

### 3. バウンディングボックスの仕様に関する注意事項

* **CVATの自動収縮仕様**: CVATのSkeletonツールは、キーポイント（FRONTとREAR）を囲む最小領域に枠が自動設定されます。
* **学習への影響なし**: 枠がタイヤの外縁まで広がっていなくても、YOLOv8-Poseは「枠内のキーポイントの相対位置関係」を学習するため、2点の検出精度や角度計算の精度には影響ありません。

---

### 4. 角度（Yaw角）計算ロジック

モデルの推論結果から得られた `FRONT` $(x_f, y_f)$ と `REAR` $(x_r, y_r)$ の画像座標を用いて、以下の計算で車体の向きを取得します。

$$\theta = \text{atan2}(y_f - y_r, x_f - x_r)$$

* 追従制御ロジック（`ai_tracker.py` 等）側では、キーポイントの信頼度（Confidence）が低いフレームにおいて前フレームの角度を維持する処理を組み込み、迷走を防止します。

---

### 5. 実験・検証ロードマップ

* **検証用データセット**: 撮影画像ファイル名に含まれる角度情報（例: `yaw+0.0`）を Ground Truth（正解値）として活用。
* **初期実験枚数**: **50〜100枚**（全方位・距離0.5〜4m・照明変化・一部遮蔽を含むバリエーション）。
* **評価手順**:
1. YOLOv8-Poseで短時間学習（20〜30 Epochs）を実施。
2. 推論結果の計算角度 $\theta_{\text{pred}}$ と、ファイル名から抽出した正解角度 $\theta_{\text{gt}}$ を照合。
3. 平均絶対誤差（MAE）を算出・検証。
