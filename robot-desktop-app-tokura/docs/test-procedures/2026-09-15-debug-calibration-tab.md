## 実機確認手順

### 1. DEBUGタブが表示されるか

1. `python main.py` でアプリを起動
2. サイドバー右下あたりに赤色の**DEBUG**ボタンが追加されていることを確認
3. DEBUGボタンをクリック → 「旋回テスト」「前進テスト」の2パネルと、下部に空の履歴テーブルが表示されることを確認
4. もう一度DEBUGボタンをクリック → メイン画面（映像）に戻ることを確認
5. DIAGNOSTICS / SNAPSHOTS / SETTINGS ボタンとの排他動作（DEBUGを開いた状態で他のボタンを押すとDEBUGが閉じる等）が壊れていないことを確認

### 2. ローバー未接続時の安全確認

1. ローバー（ESP32）が未接続の状態でDEBUGタブを開く
2. 旋回テスト・前進テストそれぞれの「RUN」ボタンを押す
3. **モーターが動かないこと**、ログパネルに `旋回テスト中止: ローバー未接続` / `前進テスト中止: ローバー未接続` が出ることを確認

### 3. 旋回テスト（実機接続）

1. ローバーを接続し、車輪が自由に回転できる場所（浮かせるか、広い床）に置く
2. DEBUGタブの旋回テストパネルで `w=190`, `実行時間=1.0` を入力してRUN
3. 実行時間経過後、車体が停止すること、ログに「旋回テスト開始」「旋回テスト終了: ジャイロ計測=...deg」が出ることを確認
4. 「ジャイロ計測値」欄に数値が表示されることを確認（未受信なら「未受信」と表示されるはず）
5. 目視で実際の回転角度をおおよそ確認し、大きく乖離している場合は「手動入力」欄に実測値を入力
6. SAVEボタンを押す → ログに保存内容が出ること、「ジャイロ計測値」表示と「手動入力」欄がクリアされること、履歴テーブルに1行追加されることを確認
7. `logs/calibration.csv` が作成され、該当行が追記されていることを確認
8. `w=-190`（逆方向）でも同様に実行し、符号が意図通り左右逆に旋回するか確認

**特に確認したい点**: ジャイロ計測値の符号・大きさが実際の回転方向・角度と合っているか（`yaw_rate`の符号がAPIドキュメントに明記されておらず未検証のため）。ズレていた場合は教えてください（`GyroYawIntegrator`側で符号反転などの調整を追加します）。

### 4. 前進テスト（実機接続）

1. ローバーの前方に十分なスペースを確保
2. 前進テストパネルで `pwm=200`, `実行時間=1.0` を入力してRUN
3. 実行時間経過後、車体が停止すること、ログに「前進テスト終了: 実測距離を入力してSAVEしてください」が出ることを確認
4. メジャー等で実際の移動距離を測定し、「実測距離(m)」欄に入力してSAVE
5. 履歴テーブルに1行追加されること、`logs/calibration.csv`に追記されることを確認
6. `pwm=-150`（後退）でも同様に実行し、正しく後退するか確認

### 5. 履歴テーブルの確認

1. 手順3・4を数回繰り返し、履歴テーブルが新しい順に表示され、直近20件で頭打ちになることを確認（21件目以降は一覧から溢れてよい。CSVファイル自体には全件残る）

### 6. 既存のfollow modeへの影響確認（回帰確認）

今回`follow_controller.py`にも変更が入っています（旋回振動対策の`spin_pulse_on_sec`短縮とバースト終了時の即時停止バグ修正）。前回までのfollow modeの確認手順（過剰旋回・前進衝突）を軽く再実行し、悪化していないことを確認してください。

## 問題があった場合

上記のどこかで期待通りに動かなかった場合、該当する手順番号と実際の挙動（ログの内容やCSVの中身が分かると助かります）を教えてください。
